# Temporal Model v0

## Playable Past

Original attested events do not change.

A visitor may:
- inspect source artifacts;
- walk through a reconstruction;
- hear or see a rendering;
- create an echo;
- dispute an interpretation;
- ask a historically bounded simulation questions.

The reconstruction must never silently become the source event.

## Playable Present

The present is the moving transition surface.

Possible actions become observed actions. Some observed actions become Attested Units.

The present therefore changes the reachable future continuously.

## Playable Future

Future scenes are projections.

They may be vivid, interactive, emotional, and persistent, but they remain explicitly conditional until events actually occur.

A future scene must carry:
- source anchors;
- assumptions;
- branch lineage;
- projection status;
- retirement/falsification conditions.

## Historical asymmetry

Past:
`attested -> echoable`

Present:
`possible -> observed -> optionally attested`

Future:
`projected -> revised / retired / realized`

## Truth rule

Immersion may increase.

Ambiguity about status must not.
