# Roadmap

## Phase 0 — Lay tiles
- dedicated repository
- provenance-preserved 2025 source
- static public surface on FC
- Past / Present / Future visual grammar
- first JSON schemas
- first example tiles

## Phase 1 — Walk the archive
- index historical Attested Units
- attach source/evidence pointers
- add search and timeline navigation
- define access/redaction states

## Phase 2 — Build worlds
- spatial scene format
- terrain/location anchors
- avatars as original stylized representations, not copies of third-party characters
- audio/video artifact playback
- echo overlays

## Phase 3 — Talk to the past
- source-bounded historical agents
- visible evidence envelope
- "attested / inferred / simulated" cues
- disagreement and alternate interpretation support

## Phase 4 — Enter the Valley
- branch graph
- transition/assumption model
- reachability tests
- rights/authority state overlays
- causal versus preferred/design-valley views

## Phase 5 — Play the present
- selected live mesh feeds
- rooms/worlds
- participant-controlled disclosure
- creation of new Attested Units from live experience

## Phase 6 — Learn from realized futures
- compare old projections with actual history
- score assumptions, not people
- preserve retired/failed branches as learning artifacts
