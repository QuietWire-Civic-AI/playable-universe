# Playable Future v0 — Scenario Worlds as Branches

## Thesis

Playable Future is the same world engine operating on a **forked state**.

The branch becomes interesting when users can inhabit it rather than merely read a scenario document.

## Scenario compilation

A future scenario contains:

- root state / time;
- branch identifier;
- assumptions;
- required transitions;
- actors;
- institutional changes;
- technology/resource changes;
- rights/authority changes;
- world/scene deltas;
- retirement conditions.

## Two event types

### Hypothetical event

A specific branch event:

`city approves autonomous curb-delivery zone`

### Simulation event

Something that happened during a play session:

`participant playing mayor rejects proposal`

Both remain inside the scenario branch.

Neither is an attested real-world event.

## Scenario engine

The first scenario engine does not need to "predict."

It needs to enforce:

- branch lineage;
- assumption visibility;
- causal ordering;
- resource/authority constraints where modeled;
- explicit uncertainty;
- alternate forks.

## Fantasy technology

The engine can support highly imaginative futures.

A scenario can introduce technology not currently available if it states:

- what capability is assumed;
- when it appears;
- what prerequisites are being assumed;
- what else becomes possible because of it.

This preserves imaginative breadth without disguising invention as evidence.

## Future NPCs / agents

Agents may inhabit future roles:

- mayor;
- engineer;
- regulator;
- customer;
- child;
- adversary;
- companion;
- institution.

Their role prompt should derive from the branch state and scenario rules rather than from a fixed generic character sheet.

## Play session outputs

A future play session can produce:

- new branch;
- decision trace;
- discovered assumption;
- contradiction;
- missing resource;
- governance failure;
- new scenario;
- retired scenario.

This turns gameplay into structured foresight.

## Realization

As real time advances, a historical future scenario can be compared with actual events.

Do not score people.

Score/model:

- assumptions;
- branch conditions;
- transition plausibility;
- overlooked dependencies;
- realized/diverged states.

The Playable Future becomes a learning record of how we imagined from earlier states.
