# Architecture v0

## First surface

The first build is intentionally static:

```
source docs + JSON
        |
        v
static site
        |
        v
fc.quietwire.ai/playable/
```

No database and no new long-lived daemon are required for v0.

## Why static first

We need to stabilize:
- ontology;
- visual grammar;
- temporal/status distinctions;
- provenance behavior;
- reachability language.

A 3D engine before those are stable would make ambiguity immersive rather than solve it.

## Later layers

### v1 — Attested world index
Read canonical/attested objects from maintained sources.

### v2 — Interactive spatial scenes
Render places, event reconstructions, and source-backed echoes.

### v3 — Historical dialogue simulation
Allow visitors to converse with bounded simulations whose source envelope is visible.

### v4 — Reachable-future engine
Represent branch assumptions and transitions explicitly.

### v5 — Live playable present
Federate selected live QuietWire/mesh events into the same temporal surface.

## Rendering boundary

Rendering is an interface.

It is not authority over the underlying Canon, evidence, Rights OS, or source repositories.
